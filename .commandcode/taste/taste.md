# Taste

## Workflow

- Wants large builds broken into explicit sequential phases (structure → install/permissions → model loading → tests) and expects a ready-to-use commit message handed back at the end of each phase; the user performs the commits themselves. Confidence: 0.85

## Tooling & Stack

- Prefers Rust-native UI frameworks (e.g. Rune, egui) over Electron-class web-wrapper desktop stacks, citing Electron's slowness as the reason to avoid it. Confidence: 0.8
